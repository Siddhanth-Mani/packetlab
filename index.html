Router>
Command reference

Try show ip interface brief, show ip route, show arp, ip address 10.0.0.1 255.255.255.0, ip route 10.1.0.0/16 10.0.0.2, router ospf 1, show vlan brief, shutdown, or no shutdown.

Commands modify the selected simulated device. This is an educational IOS-like parser, not Cisco IOS software.
